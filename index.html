05 / Cómo funciona la seguridad

Sustitución: es reversible, pero cualquiera que conozca el algoritmo puede recuperar el texto. No la uses para contraseñas ni información confidencial.

AES-GCM: cifra el texto con AES de 256 bits. PBKDF2 deriva la clave de tu contraseña mediante SHA-256. Cada cifrado utiliza un salt y un nonce nuevos; la autenticación detecta contraseñas erróneas o modificaciones del mensaje.

La web no envía los mensajes a un servidor. Aun así, usa un dispositivo de confianza y evita contraseñas débiles. GitHub Pages sirve la página, pero no almacena las claves de cifrado.
